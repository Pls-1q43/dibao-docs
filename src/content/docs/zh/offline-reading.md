Dibao 从 `v0.4.0` 起支持网页与 PWA 的离线副本。当前推荐使用 `v0.4.1`。离线阅读默认关闭，必须在每个浏览器或 PWA 单独启用；设置和缓存不会跨设备同步。

[桌面版](/zh/desktop-install/) 直接使用本机数据库，按另一套方式离线阅读，本页的缓存篇数和切换流程适用于网页与 PWA。

## 出门前准备

1. 联网登录邸报，在设置中启用离线阅读。
2. 设置推荐缓存目标，保持应用在前台等待准备完成。
3. 点击列表状态灯，确认实际可离线篇数、快照时间及待同步操作数。
4. 实际断网试读，确认能重新打开应用和正文。

除 `localhost` 或回环地址外，可靠的 PWA 离线启动需要 HTTPS。直接访问 NAS 的 HTTP 局域网 IP 不等同于离线 PWA；请先配置 HTTPS。

## 保存哪些文章

| 集合 | 数量 | 说明 |
| --- | --- | --- |
| 已排序未读推荐 | 默认 200，范围 50–1,000，步长 50 | 从已有推荐库存准备，不在浏览器重新排序。 |
| 稍后读 | 最多 200 篇副本 | 只限制离线副本，不限制服务器稍后读列表。 |
| 最近阅读 | 最多 20 篇副本 | 与其他集合重叠时只存一份正文。 |

标题和正文可读后才计入可用数量；图片尽力缓存，不保证视频、外链、所有图片或尚未取得的正文。实际篇数取决于正文、推荐库存和存储空间，目标数不是下载保证。

推荐、稍后读、收藏、最新和订阅源筛选沿用原界面，但离线时只查询缓存集合，并不代表完整服务器文章库。

## 进入与退出离线模式

断网或服务器不可达时，有缓存会询问是否切换。进入后会明确标识离线模式，并保留你的选择直到下次打开。

网络恢复不会强制退出。点击列表状态灯，在详情中选择“退出离线模式”，完成连接检查和操作同步后回到在线列表。手机阅读正文时可先返回列表找到状态入口。

## 离线操作与同步

离线时可以收藏、喜欢、稍后读、标记已读及记录阅读进度。联网后先同步操作，再更新文章状态和快照；失败项可重试。会话过期时，用同一个账户重新登录继续同步。

关闭离线阅读、清除缓存或退出登录前，先同步待处理操作。清理会丢失未同步操作，并有确认提示；服务器文章状态不会因清除本机缓存而被删除。

离线模式不提供全文搜索、相关文章、“你可能还喜欢”、刷新订阅源、打开原文及依赖在线接口的插件操作。

## 常见问题

- 可用篇数不足：确认正文已获取、推荐库存足够、空间充足；在前台继续准备。
- 图片缺失：文字正文仍可阅读，未缓存的图片需要联网。
- 无法离线冷启动：检查 HTTPS、此前是否完成登录和缓存、浏览器是否清理了站点存储。
- 手机准备被打断：系统可能暂停后台页面，保持前台并重新检查实际数量。
- 同步失败：检查同一账户的会话、服务器连通性，再重试；不要先清空队列。

浏览器存储可能被系统回收，持久存储授权也不保证成功。离线副本不是备份，清除站点数据、卸载 PWA 或空间回收均可能造成丢失。服务器备份步骤见 [备份与升级](/zh/backup-upgrade/)。
