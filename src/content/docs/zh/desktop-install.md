从 `v0.4.1` 起，邸报提供独立桌面版。应用内置运行环境，无需另外安装 Node.js、Docker 或数据库；AI 服务按需配置，不捆绑模型。

## 下载与安装

| 系统 | 安装包 | 安装方式 |
| --- | --- | --- |
| Windows x64 | [EXE 安装程序](https://github.com/Pls-1q43/Dibao/releases/download/v0.4.1/Dibao-0.4.1-win-x64.exe) | 运行安装程序，安装到当前用户目录。 |
| macOS Intel | [x64 DMG](https://github.com/Pls-1q43/Dibao/releases/download/v0.4.1/Dibao-0.4.1-mac-x64.dmg) | 打开 DMG，将 Dibao 拖入“应用程序”。 |
| macOS Apple Silicon | [arm64 DMG](https://github.com/Pls-1q43/Dibao/releases/download/v0.4.1/Dibao-0.4.1-mac-arm64.dmg) | 打开 DMG，将 Dibao 拖入“应用程序”。 |

也可从 [GitHub Release](https://github.com/Pls-1q43/Dibao/releases/tag/v0.4.1) 选择安装包，无需下载 Actions 的外层 ZIP。

当前安装包尚未签名。Windows 可能显示未知发布者，macOS 可能阻止首次启动。只使用官方 Release 下载；macOS 可在“系统设置 → 隐私与安全性”中确认打开，不要关闭系统安全校验。组织管理策略仍可能禁止运行。

## 首次使用

1. 打开应用，在欢迎页选择中文、English 或日本語。
2. 创建本机所有者账号和密码。
3. 添加 RSS / Atom 或导入 OPML，也可以选择“稍后添加”。
4. 按需配置 [Provider](/zh/providers/)，或暂时跳过。
5. 选择启用 [每日简报](/zh/plugins/daily-brief/)、[Webhook](/zh/plugins/webhook/) 等官方插件，然后开始阅读。

## 托盘与后台运行

关闭窗口会继续抓取订阅源。通过系统托盘或菜单栏的 `Open Dibao` 重新打开；选择“退出 / Quit”才完全停止。

“设置 → 关于 → 登录系统时在后台启动”默认关闭。启用后，登录系统只在后台运行，不弹出阅读器。手动启动或备份恢复后的重启仍显示窗口。未签名 macOS 版的登录项注册可能失败。

## 离线阅读

桌面版直接读取本机数据库，断网后仍能打开已保存的文章并记录阅读状态，不需要开启 PWA 缓存，也没有 PWA 的缓存篇数限制。新文章抓取、未保存的外部图片及 AI 服务仍需联网。

这是本机阅读，不是与 NAS 或远程服务器同步；跨部署导入、远程实例连接和多端同步暂未提供。网页与 PWA 的使用方式见 [离线阅读](/zh/offline-reading/)。

## 更新

在“设置 → 关于”检查更新。Windows 下载和“重启并更新”分别需要确认；普通退出不会自动安装。macOS 当前需要完全退出应用、下载新 DMG 并覆盖“应用程序”中的 Dibao。

新版本在打开数据迁移前先备份，备份失败会停止升级。稳定版不自动接收内测版，旧应用也不能直接打开新版本数据。

## 数据目录与备份

| 系统 | 数据根目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\Dibao` |
| macOS | `~/Library/Application Support/Dibao` |

可从“设置 → 关于”打开目录。`data` 保存数据库、插件数据和密钥，`profile` 保存登录和客户端状态，`backups` 保存备份。安装目录与数据分开，更新、覆盖安装、重装及默认卸载不主动删除数据。

“数据备份与恢复”支持手动创建备份、按时间选择恢复点并查看结果。操作需要确认和重启；恢复前另存当前数据，恢复点之后的改动会回退。没有有效备份时，恢复按钮不可用。

自动升级备份保留最近三份成功记录；手动备份和恢复前快照不会自动删除。备份只在本机，建议完全退出后另存整个数据根目录到其他存储介质，不要只复制 SQLite 主文件或遗漏插件密钥。

## 常见问题

- 打不开应用：检查安装包架构和系统提示；Windows ARM 原生版暂不支持。
- 找不到更新后的数据：确认仍使用原数据根目录。不要移动正在使用的目录或手工删掉密钥。
- 提示已有数据库丢失或为空：按恢复提示处理，保留残存文件；不要绕过保护创建空库。
- 更新或备份按钮不可用：先保存设置并等待数据升级结束。
- 想回退应用版本：先恢复对应版本的完整备份，再启动旧应用，详见 [备份与升级](/zh/backup-upgrade/)。
