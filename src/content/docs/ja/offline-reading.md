title: Web・PWA のオフライン読書
description: 記事キャッシュの準備、手動切り替え、操作同期と PWA のオフライン起動を説明します。
---

`v0.4.0` から Web／PWA のオフラインコピーを利用できます。現在は `v0.4.1` を推奨します。初期設定は無効で、ブラウザーや PWA ごとに有効にします。設定と保存済みファイルは端末間で同期しません。

[Desktop](/ja/desktop-install/) はローカル DB を直接読みます。本ページの保存数と切り替え手順は Web／PWA 向けです。

## 外出前の準備

1. 接続中にログインし、設定でオフライン読書を有効にします。
2. おすすめの保存目標数を選び、前面で準備の完了を待ちます。
3. 一覧の状態ランプから実際の記事数、保存時刻、未同期操作を確認します。
4. 接続を切り、アプリと本文を再び開けるか試します。

`localhost`／ループバック以外で確実に PWA をオフライン起動するには HTTPS が必要です。NAS の HTTP LAN アドレスを開くだけでは同等になりません。先に HTTPS を設定してください。

## 保存する記事

| 集合 | 数量 | 内容 |
| --- | --- | --- |
| 順位付け済み未読おすすめ | 初期 200、50–1,000、50 刻み | 保存済み順位を使用し、ブラウザーでは再計算しません。 |
| あとで読む | コピーを最大 200 件 | サーバー側のリスト数を制限しません。 |
| 最近開いた記事 | 最大 20 件 | 他の集合と重複する本文は一部だけ保存します。 |

タイトルと本文を読める記事だけを利用可能数に数えます。画像は可能な範囲で保存し、動画、外部リンク、すべての画像、未取得の本文は保証しません。本文、推薦在庫、空き容量によって実数が変わり、目標はダウンロード保証ではありません。

おすすめ、あとで読む、お気に入り、最新、フィード絞り込みは同じ画面を使いますが、オフラインの結果は保存集合だけで、サーバー全体の記事庫ではありません。

## 切り替えとオンラインへの復帰

接続またはサーバーが利用できなくなると、キャッシュがある場合に切り替えを確認します。オフライン状態を明示し、次回起動時も選択を保ちます。

接続が戻っても自動復帰しません。一覧の状態ランプから「オフラインモードを終了」を選び、接続確認と操作同期後に戻ります。モバイルの本文画面からは一度一覧へ戻って操作します。

## 操作と同期

オフラインでもお気に入り、いいね、あとで読む、既読、読書進捗を記録できます。再接続後は操作を同期し、それから記事状態と保存内容を更新します。失敗分は再試行でき、セッション切れの場合は同じアカウントでログインします。

無効化、キャッシュ削除、ログアウト前に未同期操作を送信してください。削除時には未同期操作を失う警告が出ます。ローカルコピーの削除でサーバーの記事状態は消えません。

全文検索、関連記事、個人向けの次の記事、フィード更新、原文を開く操作、オンライン API が必要なプラグイン操作はオフラインでは使えません。

## 問題への対処

- 目標より少ない：本文取得、推薦在庫、空き容量を確認し、前面で準備します。
- 画像がない：本文は読めます。未保存画像は接続が必要です。
- オフライン起動できない：HTTPS、前回の認証と保存、サイトデータ削除の有無を確認します。
- スマートフォンで準備が止まる：OS が背景ページを停止する場合があります。前面で実数を再確認します。
- 同期に失敗：同じアカウントのセッションと接続を確認して再試行します。先にキューを消さないでください。

ブラウザーストレージは OS が回収する場合があり、永続化の許可も保証されません。コピーはバックアップではなく、サイトデータ削除、PWA 削除、空き容量回収で記事や未同期操作を失う場合があります。サーバーの保存は [バックアップと更新](/ja/backup-upgrade/) を参照してください。
